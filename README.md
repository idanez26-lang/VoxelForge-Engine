# VoxelForge Engine

VoxelForge Engine est une plateforme universelle de création, d’édition, de génération et d’optimisation de contenu voxel assistée par intelligence artificielle.

> **La technologie est au service de la créativité. Jamais l’inverse.**

## Mission

VoxelForge ne remplace pas l’artiste. Il lui fait gagner du temps, automatise les tâches répétitives, propose des bases et des variantes, puis laisse toujours le contrôle créatif final à l’utilisateur.

## Périmètre initial

La première version vise un atelier de création voxel capable de :

- créer à partir de texte ;
- créer à partir d’une ou plusieurs images ;
- combiner texte et image ;
- éditer manuellement ;
- proposer plusieurs variantes ;
- conserver l’historique créatif ;
- exporter vers plusieurs formats, sans dépendre d’un moteur précis.

Teardown est une cible optionnelle parmi d’autres.

## Priorités

1. Qualité artistique
2. Liberté de création
3. Contrôle de l’artiste
4. Architecture ouverte
5. Compatibilité
6. Performances

## Arborescence

- `docs/` : spécifications et décisions
- `prompts/` : prompts destinés aux IA de programmation
- `engine/` : futur moteur sans interface
- `editor/` : futur logiciel de création
- `plugins/` : extensions
- `tests/` : tests
- `examples/` : projets d’exemple
- `assets/` : ressources autorisées du projet
- `tools/` : scripts internes
