# Installation — VF-0210 Dockspace

1. Fermer complètement Visual Studio.
2. Décompresser le ZIP dans :
   E:\VoxelForge-Engine
3. Accepter la fusion et le remplacement des fichiers.
4. Supprimer uniquement :
   E:\VoxelForge-Engine\build
   E:\VoxelForge-Engine\.vs
5. Rouvrir Visual Studio.
6. Attendre le nouveau téléchargement de Dear ImGui docking.
7. Compiler avec Ctrl + Shift + B.
8. Lancer avec F5.

Résultat attendu :
- barre de menus officielle ;
- espace de docking ;
- panneaux Hierarchy, Inspector, Viewport, Asset Browser et Console ;
- barre d'état en bas ;
- panneaux déplaçables et ancrables ;
- fermeture propre avec le code 0.
