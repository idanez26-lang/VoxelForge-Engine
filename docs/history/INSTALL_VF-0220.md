# Installation — VF-0220 Scene Foundation

1. Fermer complètement Visual Studio.
2. Décompresser le ZIP dans :
   E:\VoxelForge-Engine
3. Accepter la fusion et le remplacement des fichiers.
4. Supprimer uniquement :
   E:\VoxelForge-Engine\build
   E:\VoxelForge-Engine\.vs
5. Rouvrir Visual Studio.
6. Attendre la configuration CMake.
7. Compiler avec Ctrl + Shift + B.
8. Lancer avec F5.

Tests :
- cliquer sur Camera, Directional Light et Voxel Object ;
- vérifier que l'Inspector change ;
- modifier le nom ;
- modifier Position, Rotation et Échelle ;
- vérifier que le Viewport affiche le nom sélectionné ;
- fermer et vérifier le code 0.
