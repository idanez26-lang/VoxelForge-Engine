# Installation — VF-0211 Default Workspace

1. Fermer complètement Visual Studio.
2. Décompresser le ZIP dans :
   E:\VoxelForge-Engine
3. Accepter le remplacement des deux fichiers EditorLayer.
4. Supprimer uniquement :
   E:\VoxelForge-Engine\build
   E:\VoxelForge-Engine\.vs
5. Rouvrir Visual Studio.
6. Attendre la configuration CMake.
7. Compiler avec Ctrl + Shift + B.
8. Lancer avec F5.

Résultat attendu :
- Hierarchy automatiquement à gauche ;
- Inspector automatiquement à droite ;
- Viewport au centre ;
- Asset Browser en bas à gauche ;
- Console en bas à droite ;
- disposition toujours déplaçable et ancrable.
