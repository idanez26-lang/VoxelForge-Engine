# Installation du pack v0.0.2

1. Fermer Visual Studio.
2. Ouvrir le ZIP.
3. Copier tout le contenu du dossier `VoxelForge_Engine_v0.0.2`.
4. Coller ce contenu dans la racine du dépôt :
   `E:\VoxelForge-Engine`
5. Accepter la fusion des dossiers.
6. Rouvrir Visual Studio avec :
   `Fichier > Ouvrir > Dossier`
7. Sélectionner :
   `E:\VoxelForge-Engine`
8. Attendre la configuration CMake.
9. Choisir la cible `VoxelForgeEditor`.
10. Cliquer sur le triangle vert pour lancer.

Aucun fichier existant de documentation ne doit être supprimé.
