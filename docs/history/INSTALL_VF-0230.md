# Installation — VF-0230 Viewport 3D Prototype

1. Fermer complètement Visual Studio.
2. Décompresser le ZIP dans :
   E:\VoxelForge-Engine
3. Accepter la fusion et le remplacement.
4. Supprimer uniquement :
   E:\VoxelForge-Engine\build
   E:\VoxelForge-Engine\.vs
5. Rouvrir Visual Studio.
6. Attendre CMake.
7. Compiler avec Ctrl + Shift + B.
8. Lancer avec F5.

Tests :
- la grille 3D doit apparaître ;
- le cube orange doit apparaître ;
- maintenir clic droit dans Viewport ;
- déplacer la souris pour regarder ;
- utiliser W A S D ;
- utiliser Q et E ;
- maintenir Shift pour accélérer ;
- utiliser la molette ;
- modifier la position de Voxel Object dans Inspector ;
- vérifier que le cube se déplace ;
- fermer avec le code 0.
