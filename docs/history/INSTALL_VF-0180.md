# Installation — VF-0180 Window SDL3

1. Fermer Visual Studio.
2. Décompresser le ZIP dans `E:\VoxelForge-Engine`.
3. Accepter la fusion et les remplacements.
4. Supprimer uniquement `build` et `.vs`.
5. Rouvrir le projet dans Visual Studio.
6. Attendre le téléchargement/configuration de SDL3.
7. Compiler avec Ctrl + Shift + B.
8. Lancer `VoxelForgeEditor.exe` avec F5.
9. Fermer la fenêtre avec la croix.

Résultat attendu :
- fenêtre `VoxelForge Editor` en 1280 x 720 ;
- fenêtre redimensionnable ;
- fermeture propre avec le code 0.
