# Installation v0.0.3 FIXED

1. Fermer Visual Studio.
2. Décompresser le ZIP.
3. Copier tout le contenu du dossier extrait.
4. Coller dans `E:\VoxelForge-Engine`.
5. Accepter la fusion et le remplacement.
6. Supprimer le dossier `build` du dépôt pour forcer une configuration propre.
7. Rouvrir `E:\VoxelForge-Engine` dans Visual Studio.
8. Attendre la fin de CMake.
9. Lancer `VoxelForgeEditor`.
