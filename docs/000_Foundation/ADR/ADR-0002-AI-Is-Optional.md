# ADR-0002 — L’IA est optionnelle

**Statut :** Accepté

## Décision

Le moteur voxel, l’éditeur, les Builders, les exports et les projets doivent fonctionner sans fournisseur d’IA.

## Justification

Les modèles d’IA changent rapidement. VoxelForge ne doit jamais être bloqué par une API, une connexion ou un fournisseur particulier.
