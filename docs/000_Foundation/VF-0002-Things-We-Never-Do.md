# VF-0002 — Ce que VoxelForge ne fera jamais

- Remplacer volontairement l’artiste.
- Imposer une seule manière de travailler.
- Dépendre d’un fournisseur d’IA unique.
- Dépendre d’un moteur de jeu précis.
- Enfermer les créations dans un format propriétaire sans export.
- Modifier irréversiblement un projet sans validation.
- Cacher les paramètres importants d’une génération.
- Mélanger les connaissances métier avec le code du moteur.
- Accepter des modules gigantesques impossibles à maintenir.
- Prioriser une démonstration spectaculaire au détriment d’une base solide.
