# PROMPT-000 — Règles destinées aux IA de programmation

Tu travailles sur VoxelForge Engine.

Avant toute modification :

1. Lis le PRD.
2. Lis la Constitution.
3. Lis le Domain Model.
4. Lis les ADR liés au module.
5. Identifie précisément le périmètre demandé.
6. Ne développe pas de fonctionnalités non demandées.
7. Ne crée pas de mocks présentés comme des fonctionnalités finales.
8. Ne couple jamais le moteur à un fournisseur d’IA ou à une cible d’export.
9. Préserve le contrôle final de l’artiste.
10. Ajoute ou mets à jour les tests et la documentation.

Pour chaque tâche, fournis :

- les fichiers modifiés ;
- les décisions prises ;
- les hypothèses ;
- les tests ;
- les limites restantes ;
- les éventuels nouveaux ADR nécessaires.
