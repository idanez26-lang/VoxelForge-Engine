# Installation — VF-0240 Renderer Foundation

1. Fermer Visual Studio.
2. Décompresser dans E:\VoxelForge-Engine.
3. Accepter fusion et remplacements.
4. Supprimer uniquement build et .vs.
5. Rouvrir Visual Studio.
6. Attendre CMake.
7. Compiler avec Ctrl + Shift + B.
8. Lancer avec F5.

Résultat attendu : VoxelForgeRenderer.lib et VoxelForgeEditor.exe compilent, sans changement visuel ni régression.
