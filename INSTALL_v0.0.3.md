# Installation du pack v0.0.3

1. Vérifier que la version v0.0.2 compile.
2. Fermer Visual Studio.
3. Décompresser le pack v0.0.3.
4. Copier tout le contenu du dossier extrait.
5. Coller dans :
   `E:\VoxelForge-Engine`
6. Accepter la fusion et le remplacement des fichiers.
7. Rouvrir Visual Studio sur :
   `E:\VoxelForge-Engine`
8. Attendre la configuration CMake.
9. Sélectionner `VoxelForgeEditor`.
10. Lancer avec le triangle vert.

Le programme doit créer :

`E:\VoxelForge-Engine\workspace\DemoProject\project.json`

Le dossier `workspace/` est ignoré par Git.
