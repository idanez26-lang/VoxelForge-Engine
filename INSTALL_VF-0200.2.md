# Installation — VF-0200.2 First ImGui Window

1. Fermer complètement Visual Studio.
2. Décompresser le ZIP dans :
   E:\VoxelForge-Engine
3. Accepter la fusion des dossiers.
4. Accepter le remplacement des fichiers.
5. Supprimer uniquement :
   E:\VoxelForge-Engine\build
   E:\VoxelForge-Engine\.vs
6. Rouvrir le projet dans Visual Studio.
7. Attendre la régénération CMake.
8. Compiler avec Ctrl + Shift + B.
9. Lancer VoxelForgeEditor.exe avec F5.

Résultat attendu :
- fond sombre ;
- fenêtre « VoxelForge Editor » ;
- fenêtre de démonstration Dear ImGui ;
- case à cocher interactive ;
- bouton À propos ;
- fermeture propre avec le code 0.
