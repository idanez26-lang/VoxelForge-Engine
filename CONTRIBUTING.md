# Contribution

Toute contribution doit :

- respecter la Constitution ;
- être reliée à une issue ou une spécification ;
- inclure des tests lorsque du code est ajouté ;
- mettre à jour la documentation ;
- éviter les dépendances inutiles ;
- préserver le contrôle final de l’artiste ;
- signaler toute incompatibilité ou migration.
